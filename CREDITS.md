# Credits and acknowledgements

Interactive Alice exists because of a book someone else wrote first. This file
records what it is built on, and how that should be credited in the experience
itself.

## The story

*Alice's Adventures in Wonderland*, written by **Lewis Carroll** (Charles
Lutwidge Dodgson, 1832–1898) and first published in **1865**. The work is in
the public domain, so no permission is needed to retell it. Crediting it is a
matter of respect rather than of licence, and this project credits it anyway.

## The English source text

The original English used as source material comes from **Project Gutenberg
eBook #11** (https://www.gutenberg.org/ebooks/11), the Millennium Fulcrum
Edition transcription. Project Gutenberg claims no copyright in the
transcription; full provenance, checksums, and the trademark question are
documented in [`text/raw/SOURCE.md`](text/raw/SOURCE.md).

Project Gutenberg's volunteers made a 160-year-old book freely readable by
anyone with a browser, which is a large part of why this project is possible.

## What this project adds

Everything a visitor reads in the experience is new writing, not the 1865 text:
a child-friendly retelling in short sentences, translated per language from
that retelling. The visual identity, scene design, code, and sound are original
to this project. Interactive Alice is not affiliated with, and does not draw on,
any later adaptation of the story; only the public-domain 1865 work.

## Credit shown in the experience

The finished site should carry this, reachable from the entry scene and the
end of the story:

> Retold from *Alice's Adventures in Wonderland* by Lewis Carroll, 1865.
> A public-domain work. English source text: Project Gutenberg eBook #11.
> This retelling, its translations, artwork, and code are original to
> Interactive Alice.

Translators and contributors are credited here as they join.
